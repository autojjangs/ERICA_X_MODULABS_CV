# 프로젝트 목표와 작업 기록

## 목표

같은 EfficientDet-D0 가중치에서 입력 해상도와 confidence를 바꾸며 차량 탐지의 정확도·속도를 비교한다. 검증 데이터로 선택한 설정을 고정하고, 원본·어두움·흐림에서 누락이 어떻게 달라지는지 분석한다. 차량 관련 주제를 다루면서 2시간 안에 결과와 회고를 정리할 수 있도록 추가 학습 없이 추론 조건 비교에 집중했다.

실행 환경은 VS Code의 Google Colab GPU 커널, 데이터는 공개 Vehicle Detection Image Dataset이다. 공장 출입구·물류 구역의 차량 모니터링을 응용 시나리오로 두었으며, 실제 실험은 도로 이미지로 수행했다.

## 실험 조건

| 항목 | 확정 조건 |
| --- | --- |
| 모델 | COCO 사전학습 EfficientDet-D0, FP32, batch 1 |
| 검증·평가 | 각각 60장, 시간 구간 분리 및 경계 간격 30프레임 |
| 입력·임계값 | 512/768 × 0.1/0.3/0.5 |
| 선택 기준 | 원본 검증 F1 최대, 정확한 동률이면 중앙 처리 시간 최소 |
| 열화 | 밝기 0.6배, Gaussian blur 5×5·sigma 1.0 |
| 지표 | Precision·Recall·F1·AP50, 처리 시간, 차량 수 MAE, 작은 차량 Recall |

## 결론과 다음 범위

해상도를 높인 조건에서 누락이 줄었지만 처리 시간은 증가했다. 작은 차량과 밀집 장면의 누락은 여전히 크다. 다음 실습에서는 속도 반복 측정과 열화 강도 비교를 진행하고, 다른 촬영 장소의 데이터로 일반화 여부를 확인한다. 자세한 실행 기준은 [KPT](PERSONAL_REFLECTION.md)에 기록했다.
