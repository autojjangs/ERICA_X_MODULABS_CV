## 공개 절차

1. GitHub에 공개 저장소를 만들고 README, 코드, 설정, 노트북, 문서와 결과 파일을 올린다. 전체 데이터·가중치·계정 키는 제외한다.
2. 로그아웃 또는 시크릿 창에서 README·노트북·그래프가 열리는지 확인한다.
3. 실제 주소와 확인 시각을 이 표 및 노트북의 공개 확인 셀에 기록한다.
4. 공개 확인 셀을 실행해 결과 ZIP을 다시 저장하고, 강의 제출 위치에 README URL을 제출한다.

GitHub에서 노트북 미리보기가 되지 않으면 다운로드 가능 여부를 확인하고 Colab 열람 링크를 함께 사용할 수 있다. 로컬 경로는 외부 제출 링크로 사용할 수 없다.
