# 실습 코드를 읽는 세 가지 해설 노트북

실습 파일 옆에 두고 읽는 초보자용 해설입니다. 실습은 원래 `notebooks/`의 00·01·02에서 진행합니다.

| 원래 실습 | 함께 읽을 해설 | 설명하는 내용 |
|---|---|---|
| [00 · 모델과 데이터 준비](../notebooks/00_hf_download_and_data.ipynb) | [00 · 코드 해설](00_hf_download_and_data_explained.ipynb) | 환경과 라이브러리, 다운로드, 파일 지문, 이미지·라벨, 데이터 분할과 저장 |
| [01 · GPU 추론](../notebooks/01_gpu_inference.ipynb) | [01 · 코드 해설](01_gpu_inference_explained.ipynb) | 이미지와 텐서, Pipeline, 모델 점수, Top-k, 검사와 결과 저장 |
| [02 · GPU 파인튜닝](../notebooks/02_gpu_finetuning.ipynb) | [02 · 코드 해설](02_gpu_finetuning_explained.ipynb) | 미니배치, 손실과 가중치 갱신, 학습 범위, 모델 선택, 평가와 저장·복원 |

각 해설에는 원본의 모든 코드 셀이 들어 있습니다. 원본 코드는 **읽기용 Markdown 코드 블록**으로 보여 주고, 그 뒤에서 변수·문법·계산 순서·결과와 흔한 실수를 설명합니다. 셀 번호는 원본의 설명 셀까지 포함한 위치이며 `In [ ]`에 나타나는 실행 순서와는 다릅니다.

해설본에서 실행할 수 있는 코드 셀은 Python 기본 기능만 사용하는 작은 예제입니다. Codespaces의 CPU 커널에서 위에서부터 실행할 수 있으며, 모델 다운로드·Google 인증·Colab GPU 생성·실제 학습은 하지 않습니다. 예제에 저장된 출력은 이 작은 코드의 실행 결과이며 실제 모델의 정확도나 GPU 결과가 아닙니다.

01·02의 네 핵심 함수는 실습본과 해설본 모두 완성된 코드로 볼 수 있습니다. 해설에서 입력·출력과 계산 순서를 읽고, 실습본에서는 제공된 확인 셀로 결과를 점검합니다. 실행 후 조건을 바꾸는 방법은 [핵심 코드 실습 안내](../ai-coding-workshop.md)를 따르세요.

처음 읽을 때는 각 셀의 목적과 입력·출력을 먼저 보고, 이해가 되면 줄별 설명을 읽으면 됩니다. 모르는 단어는 마지막 용어 정리에서 다시 확인하고, 작은 예제의 숫자를 바꾸기 전에 결과를 예상해 보세요.

원본 코드를 수정할 때에는 대응하는 해설도 함께 갱신합니다. 저장소 검사는 해설에 인용한 코드와 원본이 같은지, 빠진 셀이 없는지 확인합니다.
