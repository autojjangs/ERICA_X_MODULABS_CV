# 수업 후 참고: 양자화

이 자료는 선택 읽기 자료다. 필수 실습·평가·GPU 실행 완료 조건에 양자화를 넣지 않는다. 이번 프로젝트의 실제 학습과 측정은 FP32로 수행했다.

양자화는 가중치나 활성값을 더 적은 비트로 표현해 모델 저장 공간과 연산 비용을 줄이는 방법이다. 예를 들어 정수 양자화에서는 실수 범위를 정수 범위에 대응시키는 scale과 zero point 같은 정보를 함께 사용한다. 숫자의 정밀도가 줄면서 예측이 달라질 수 있다.

| 용어 | 의미 |
|---|---|
| FP32 | 이번 수업의 기본 실수 표현 |
| BF16·FP16 | 낮은 정밀도의 부동소수점 표현. INT8 정수 양자화와 구분 |
| PTQ | 학습을 마친 모델을 대상으로 하는 양자화 |
| QAT | 양자화로 생길 오차를 고려하면서 학습하는 방법 |

실험한다면 먼저 이번 FP32 체크포인트와 테스트 결과를 기준으로 저장한다. 선택한 실행 환경에서 지원하는 양자화 도구를 사용하고, 필요한 보정에는 학습 데이터 일부를 사용한다. 테스트 이미지를 보정이나 설정 선택에 사용한 뒤 같은 이미지로 성능을 평가하지 않는다.

비교할 항목은 파일 크기, 같은 테스트 데이터의 정확도·클래스별 오류, 실제 장치의 지연시간이다. 가중치 비트를 줄였다고 모든 GPU·TPU에서 자동으로 빨라지는 것은 아니다. 해당 연산과 장치가 낮은 정밀도 커널을 지원하는지도 확인해야 한다.

가중치의 자료형을 단순히 정수형으로 바꾸는 것만으로 올바른 양자화 추론기가 완성되지는 않는다. 이번 코드의 체크포인트를 임의로 정수형으로 바꾸지 않는다. 별도의 구현과 검증이 필요한 확장 주제다.

추가 읽기: Benoit Jacob 외, [Quantization and Training of Neural Networks for Efficient Integer-Arithmetic-Only Inference](https://arxiv.org/abs/1712.05877). 정수 양자화와 학습을 연결하는 원리를 설명하는 원 논문이다.
