# IC-PBL 팀활동보고서

## 미팅 개요

| 항목 | 내용 |
|---|---|
| 팀이름 | 핑거 프린세스 |
| 일시 |  2026-10-20|
| 참석자 | 장기준, 이찬샘, 이승준 |
| 문제해결과정 | 제스처 인식을 실제 화면 조작에 연결하고, 손 미검출과 동작 전환 시 오작동을 줄이기 위한 제어 방식을 점검했다. 장갑·조명별 실험으로 사용 환경에 따른 인식 한계와 개선점을 도출했다.   |
| 본 미팅의 주요활동 | MediaPipe·MLP 기반 데스크탑 PoC와 Handy의 Whisper Small 음성 검색을 연결했다. 맨손·비닐장갑·검정 라텍스 장갑과 조명 ON·OFF 조건에서 실사용 실험을 진행하고 결과를 정리했다. |

## 진행 사항

| 항목 | 내용 |
|---|---|
| 이번 미팅에서 한 일(활동 내용) | 제스처 제어와 음성 검색을 점검하고 장갑·조명별 실사용 실험을 진행했다. 조명 ON, 거리 1.2m에서 연속 명령을 오류 없이 마친 시행은 맨손 7/10회(70%), 비닐장갑 2/5회(40%)였다. 검정 라텍스는 0.75m에서도 손 검출 실패가 반복됐고, 조명 OFF에서는 맨손·비닐장갑 모두 제어가 불안정했다. |
| 이번 미팅에서 한 일(조치 사항) | 손 미검출과 잠금을 구분하도록 상태별 허용 명령을 구성했다. FIST를 NoGesture에 포함하는 데이터 보강 방향을 반영하고, 음성 입력 시작·종료의 안정성을 추가 점검하기로 했다. |
| 논의 사항 | 장갑과 저조도 조건에서 나타난 손 검출 실패, Pinch 누락과 음성 입력 오류를 개선 과제로 정했다. 실험 수치는 개별 명령의 정확도가 아닌 연속 명령의 무오류 완료 비율로 제시하고, 시행 수가 없는 저조도·라텍스 결과는 관찰 내용으로 설명하기로 했다. |
