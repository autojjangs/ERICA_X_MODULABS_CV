# Press Release

## 비전 모델과 제스처 학습으로 요리 중에 스마트폰을 만지지 않고 조작하기

요리 중 스마트폰을 만지지 않고 레시피와 조리 영상을 조작하는 기능을 선보이고자 한다. 앱을 실행하고 지원하는 브라우저나 영상 플랫폼에 접속하면, 카메라가 손 모양을 인식해 스크롤과 영상 일시정지/재생을 실행한다.

이 프로젝트는 아래와 같이 요리 중 반복되는 세 가지 불편에서 착안되었다.

1. 식재료나 양념이 묻은 손으로 스마트폰을 만지면 화면이 더러워지고 식재료와 기기 사이의 접촉이 늘어난다.
2. 젖거나 기름진 손으로는 터치가 원하는 대로 반응하지 않을 수 있다.
3. 이를 피하려고 손을 씻고 닦거나, 조리 속도에 맞춰 영상을 멈추고 다시 재생할 때마다 흐름이 끊어진다.

사용자는 조리 전에 앱을 켜고 스마트폰을 거치한 뒤, 익숙한 웹 레시피나 영상을 연다. 웹 페이지에서 는 한 손으로 제스처를 취하면 스크롤이 되어 다음 내용을 확인할 수 있고, 영상에서는 필요한 순간에 멈추고 준비가 끝나면 이어볼 수 있다. 자체 레시피를 제공하는 대신 기존 콘텐츠의 이용을 돕기 때문에, 레시피를 별도로 옮길 필요가 없다.

기술의 중심은 손의 위치와 형태를 추정하고 제스처를 분류하는 비전 모델이다. 사전학습된 MediaPipe 모델로 손의 21개 주요 지점인 랜드마크 좌표를 추출하고, 이 좌표를 입력으로 받는 작은 신경망인 MLP를 직접 학습했다. 손목 위치와 손 크기를 기준으로 좌표를 정규화해 위치와 거리의 영향을 줄였다. 손의 위치와 형태를 검출하는 모델은 MediaPipe Hands 모델을 그대로 사용하고, 실제로 스마트폰을 조작하기 위한 제스처를 분류하는 작업에 집중했다.

이전에는 양념을 버무리다가 손을 씻고 닦아 화면을 넘기거나 영상 재생을 멈춰야 했다. 이제는 조리 도구를 내려놓고 한 손으로 제스처를 취해 필요한 정보를 확인할 수 있다. 이 프로젝트의 핵심 가치는 화면 접촉과 조리 중단을 줄이면서, 레시피와 영상을 사용자의 속도에 맞춰 이용하게 하는 것이다. 이를 뒷받침하는 연구 성과는 주방 상황의 제스처 데이터, 학습한 분류기, 그리고 모델 비교와 실패 분석으로 제시한다.

# Frequently Asked Question

## 1. 이 프로젝트는 누구를 위한 것인가?

스마트폰으로 레시피나 조리 영상을 보며 요리하는 사람을 위한 것이다. 손이 젖거나 양념이 묻어 화면을 만지기 어려운 상황에 초점을 둔다.

## 2. 어떤 문제를 해결하는가?

접촉에 따른 오염과 위생상의 부담, 젖거나 기름진 손의 터치 불편, 반복적인 화면 조작으로 생기는 조리 중단을 줄인다. 위생상의 가치는 접촉 감소에 한정한다.

## 3. 어떻게 이용하는가?

조리 시작 전에 앱과 카메라 인식을 시작하고 스마트폰을 거치한다. 지원하는 브라우저나 영상 플랫폼에서 콘텐츠를 연 뒤, 손 제스처로 명령을 내린다

## 4. 어떤 기능을 제공하는가?

웹 레시피의 위아래 스크롤과 조리 영상의 일시정지와 재생을 제공한다. 각 기능은 현재 앱과 화면에서 지원되는 경우에 동작한다.

## 5. 컴퓨터비전 프로젝트로서 핵심 기여는 무엇인가?

사전학습 손 검출 모델의 활용, 주방 상황의 데이터 수집, 경량 제스처 분류기의 학습과 비교 평가이다. 화면 제어는 모델 결과를 확인하는 응용 단계로 생각한다.

## 6. 조리 동작으로 인한 제스처 오인을 어떻게 방지할 수 있는가?

명령이 아닌 손동작도 학습하고, confidence가 낮은 결과는 거부한다. 조작 모드 도입이나 제스처 유지 시간 등의 도입을 고려 중이다.

## 7. 모델과 시스템 성능은 어떻게 검증하는가?

기본 제스처 인식 방식과 학습한 분류기를 같은 시험 데이터로 비교할 계획이다.

## 8. 기존에 존재하는 Pre-trained 모델은 어떻게 활용하고 추가 학습은 어떻게 진행하는가?

Pre-trained 모델은 MediaPipe Hands를 활용하고 프로젝트에 필요한 제스처 분류기를 추가로 학습하는 방식으로 프로젝트를 계획했다. MediaPipe Hand Landmarker는 영상에서 손의 21개 주요 지점인 랜드마크 좌표를 추출하며, Gesture Recognizer는 손바닥 펼치기, 주먹, 엄지 올리기 등의 기본 손 모양도 인식한다. 초기 구현에서는 이러한 기본 제스처를 스크롤, 영상 일시정지/재생에 연결해 전체 동작을 먼저 확인한다.

추가 학습으로는 추출한 랜드마크 좌표를 입력 받는 작은 신경망인 MLP를 학습한다. 손목을 기준으로 좌표를 이동하고 손 크기로 정규화해 촬영 위치와 거리에 따른 영향을 줄인다.

학습 데이터는 여러 사람이 명령(조작)용 손 모양을 취하는 모습을 촬영해 마련할 계획이다.
