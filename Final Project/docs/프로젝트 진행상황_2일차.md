# IC-PBL 팀활동보고서

## 미팅 개요

| 항목 | 내용 |
|---|---|
| 팀이름 | 핑거 프린세스 |
| 일시 | 2026-10-16 |
| 참석자 | 장기준, 이찬샘, 이승준 |
| 문제해결과정 | 기존의 포인터 방식은 사용자가 검색 기능을 사용하는데 오히려 불편함이 있었는데, STT를 도입하여 한계를 극복해냄 |
| 본 미팅의 주요활동 | 본 프로젝트에서 사용할 모델은 MediaPipe Gesture Recognition, Whisper Small로 결정했고, 제스처 데이터셋은 HaGRIDv2 Annotations(MLP 학습용 손 관절 좌표와 제스처 레이블), HaGRID GitHub(데이터셋 설명, 학습 코드, 다운로드 스크립트), Dynamic Gestures GitHub(Swipe, Click, Drag 등 동적 제스처 구현 참고)을 사용하기로 결정했다. 또한 기존의 포인터 방식으로 한계가 있었던 검색 기능은 handy에서 Whisper Small 모델을 사용하여 STT 기능으로 처리하는 것으로 결정했다. |

## 진행 사항

| 항목 | 내용 |
|---|---|
| 이번 미팅에서 한 일(활동 내용) | 이번 미팅에선 제스처 데이터셋을 이용해서 peace, one, stop, no_gesture 총 4개의 레이블로 정의해 MLP를 학습시켜 보았고, MediaPipe가 동작을 잘 구분하는 것을 확인했다. 또 검색 기능을 포인터로 처리하려고 하니 오히려 사용자가 번거로운 경험을 할 수 있다는 것을 확인하여 검색 기능은 STT 방식으로 처리하도록 수정했다. |
| 이번 미팅에서 한 일(조치 사항) | 포인터 방식으로 검색 기능을 사용하려고 하니 오히려 사용자가 더 불편함을 겪을 수 있다는 것을 알게 되어 STT 방식으로 한계점을 극복함 |
| 논의 사항 | MediaPipe가 동작 구분을 잘하는 것을 확인해서 트리거 동작에 매칭할 액션 동작을 생각해봐야 하고, 다음 논의 시간엔 PoC 구현을 완전히 하는 것을 목표로 했다. |
